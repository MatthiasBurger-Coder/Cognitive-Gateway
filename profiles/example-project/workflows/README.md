# Example Workflows

Reserved for machine-readable project workflow definitions and state transitions. Workflow definitions are loaded from the profile and resolved by the deterministic core.

Concrete example workflows are introduced with the profile-loader and vertical-slice work in CG-03/CG-09.

There are intentionally no workflow fixtures or workflow component tests in this directory yet. The current test suite covers the validated domain primitives and the context compiler; workflow loading, resolution and state-transition tests belong here once executable workflow definitions and their loader are introduced.
